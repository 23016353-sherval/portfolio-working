FINAL YEAR PROJECT

~~INTRODUCTION~~

This is my Final Year Project (FYP) called Promptr and for this Project we used REACT for the frontend and Firebase for the backend. We chose these 2 systems because firstly, REACT was the main thing we were taught so it was easier to apply, second we used firebase because there would be some extra points for using systems that we have not learned before.

The objective of the project was to help users (mainly students aged 12-24) improve on their prompt engineering skills given the rise of AI. To accomplish this, we decided to make it as a web game where you generate an image based on the photograph given to make it easier and more fun for the users to use and learn. There are 2 different game modes, first is a single player mode where you can practice on your own and the other is a multiplayer mode where you can compete with other players in a lobby.

Additionally, this project was one of the few being showcased during the next year's open house for propecting students. This project was also selected to be featured on Channel 8 News.

~~GAMEPLAY~~

First, let me explain the gameplay, the goal of the game is to write a prompt that will generate an image as close to the original photo as possible while trying to bypass our AI image detection. The game starts with you being given a random animal photograph taken from an online image bank (Unsplash), after the image generates, one AI will compare the 2 images based on how close the images are and another AI will determine whether it looked AI or human-made as well as give detailed feedback on which parts made it obvious and one more AI will check how close the description of the photograph is to the prompt that was written, each point will give a percentage score and the total score will be the average of both scores.

For singleplayer mode, simply called Promptr, You will be given 3 tries daily to practice your prompt engineering skills. Once you are satisfied with your score, you can upload your score to a live leaderboard either anonymously or by giving a display name, and see how well you did against other players.

For local multiplayer mode called PromptWars, you create a lobby and people can join with a room code, once everyone is in, the host can start the game and everyone will be given the same photo. They will all write their own prompts up to 5 tries per round, select their favourite image and submit it, after everyone has submitted their image, or the time runs out, it will move on to the next round. Once all the rounds are over, the scores will be revealed and the player with the highest score wins. The scores will then be added to a separate leaderboard for PromptWars which compares the scores of all the players that have played PromptWars.

~~DESIGN~~

For the single player mode we went for a more calm and simple design to fit the more relaxed and practice nature of the game mode. For PromptWars we went for a more playful design and music to fit its competitive and fun nature. We also gave them different colour schemes, with PromptWars having a more vibrant colour scheme and Promptr having a more muted colour scheme. To futher differentiate the 2 modes, we also gave them different logos, with PromptWars having a more playful logo and Promptr having a more simple logo.

~~Development~~

For the Starting images, we decided to use photographs of animals from unsplash because you can go into more detail when describing animals like fur or feathers, full body or half body, etc. and we thought it was better to use real images rather than AI images as the reference picture.

Next are the AI models used for Image Analysis & Feedback, Image Generation, Image Detection and Prompt & Image Description Comparison.** For image analysis and feedback we used Gemini-2.0-flash as it was one of the more recent and advanced models for this purpose. For image generation we used Gemini-2.0-flash-experimental-image-generation becuase it was a model more catered to image generation compared to the regular Gemini-2.0-flash. For image detection we used the hugging face model called haywoodsloan as it was a good model for detecting whether the images are AI generated or not. And the last model for prompt and image description comparison was also a hugging face model called MiniLM which give the most accurate results for what we needed.

** --- all the AI models listed above are accurate to my latest knowledge in August 2025. The models may have since been updated or changed, but these were the models used at the time of development.

ISSUES FACED

As fun as this project was, there were some issues we faced along the way, while we managed to fix them in the end, they were still quite a hassle to deal with. Let me list some of the issues we faced during development and design.

API issues, occationally the API would fail to generate images or fail to analyze the images, this was quite a problem as it would affect the gameplay and user experience, sometimes it was on the side of the API providers so we could not really do much about it, but other times it was due to our own code and we had to spend time debugging and fixing the code to make it work properly.

Another issue we had was that we would exceeed the API limits quite easily during testing which made it hard to test the game properly, to fix this we made sure that only one person or maximum 2 people were testing the game at any time and we would try to test multiple things in one go to make the most out of the API calls we had.

The next issue we had was contridicting AI results. For example, our AI detection result had stated that no AI generation was used, however Gemini's analysis stated that AI was strongly indicated for the image. Fortunately this was a one time thing and did not happen again.

~~OVERALL~~

Overall this project was a really fun and rewarding experience, it was a great way to apply what we have learned in class and also learn new things along the way. We were able to create a game that is not only fun to play but also helps users improve their prompt engineering skills which is really satisfying. We also got to showcase our project during the open house and on Channel 8 News which was a great experience as well. If I were to do this project again, I would probably try to add more features and make the game more polished, but overall I am really happy with how it turned out.
